ต้องใช้มือถือที่มีเซ็นเซอร์การเคลื่อนไหวและไมโครโฟน
เซ็นเซอร์ที่ใช้: Accelerometer ผ่าน DeviceMotionEvent (วัดความแรงในการเขย่า) และ Microphone ผ่าน Web Audio API (วัดระดับความดังของเสียง)

วิธีทำงานร่วมกัน: พลังรวม = ระดับแรงเขย่า × ระดับความดังเสียง (ทั้งสองค่าอยู่ในช่วง 0–1) ถ้าถอดเซ็นเซอร์ตัวใดตัวหนึ่งออก ค่าตัวนั้นจะเป็น 0 เสมอ และพลังรวมจะเป็น 0 ตามไปด้วย — ต้องมีทั้งสองตัว ทำงานพร้อมกันจริง ๆ เกจถึงจะขึ้นและระฆังถึงจะดังได้
